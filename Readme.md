While I may not be an AI expert or anything close to it, I do know at least as much as needed for a basic understanding of the working of LLMs. LLMs, or Large Language Models, are mathematical models that, when given an input,  fabricate an output based on a type of reinforcement "learning" done on the model called the model training process. Though it can't be called learning in its truest sense, since all the model is doing is memorizing the pattern of output for a given input. All LLMs essentially work with something called a neuron. The terminology is borrowed from the era of the first AI boom, when Walter Pitts and Warren McCulloch gave the idea of an artificial neuron. It is some node or state (if we borrow automata terminology) that has a weight attached to it. The weight represents a connection between two neurons. These weights are usually floating-point numbers, with positive numbers showing an excitatory connection while negative weights show an inhibitory connection. Multiple neurons at the same level make up a single layer. The output from a neuron in the first layer is used to calculate the input for a neuron in the next layer, and so on. And so, an Artificial Neural Network (ANN) consists of multiple layers, specifically: An input layer, N number of hidden layers, and an output layer. The modern LLMs based on the [Transformer Model](https://arxiv.org/pdf/1706.03762.pdf) use a concept called "Self-Attention" where each Token (a word/subword) incorporates context with respect to all the other tokens in a sentence. These Transformer-based models allow much greater parallelization from the tradational RNNs, LSTM, Gated RNNs, etc. Still, even the basis for LLMs remains the same: Massive Feed-Forward Neural Networks fitted using trillions of bytes of data. These models do not have any cognition, only a mapping from one neuron to another based on the connections formed during the training process, a form of memorization. In fact, any good LLM is just a very good word guesser.
